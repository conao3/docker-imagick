* Description
A lightweight Docker image for [[https://github.com/ImageMagick/ImageMagick][ImageMagick]], providing a portable and consistent environment for image processing tasks.

* Install
This image requires Docker to be installed on your system.

#+begin_src bash
brew install docker
brew cask install docker

# Verify Docker installation
docker version
#+end_src

* Usage
Run the container to access ImageMagick commands:

#+begin_src bash
docker run -it conao3/imagick
#+end_src

Example output:

#+begin_example
